# DXSpider documentation

Guides and technical resources for DXSpider SYSOPs.

## Upgrade guides

| Language | Guide |
| --- | --- |
| English | [DXSpider Mojo Upgrade Guide](DXSpider-Mojo-Upgrade-Guide-%28EN%29.md) |
| Español | [Guía de actualización de DXSpider](Gu%C3%ADa-de-actualizaci%C3%B3n-de-DXSpider-%28ES%29.md) |

Both guides describe manual upgrades and the DXSpider Manager method, including build-dependent BadIP update schedules. Choose the instructions appropriate for your installed build and review your local configuration before applying changes.
